# Лаборатори 3 — Чанарын сценарио ба SLO

**Д.Бүрэнтөгс · B222270092**

## Чанарын сценарио

| Хэсэг | Гүйцэтгэл | Найдвартай байдал | Бэлэн байдал | Тайлангийн хурд |
|---|---|---|---|---|
| Тойм | Сагсанд бараа хурдан нэмэх | Төлбөрийг амжилттай боловсруулах | Зогсолтын дараа API-г сэргээх | Тайланг хугацаанд нь өгөх |
| Системийн төлөв | API хэвийн ажиллаж байгаа | Төлбөрийн үйлчилгээ ажиллаж байгаа | API хүсэлт авч байх үед процесс унана | Тайлангийн зам ажиллаж байгаа |
| Орчны төлөв | Локал, 20 VU, 1 минут, 20 VU-ийн бодит хурдыг доор тэмдэглэв | Локал, 20 VU, 1 минут, 20 дахь төлбөр бүрт зориуд алдаа гарна | Локал, 20 VU, 2 минут, 10 секундийн төлөвлөсөн зогсолт | Локал, 20 VU, 1 минут, 200–400 мс хүлээлттэй |
| Гадаад өдөөлт | Хэрэглэгч сагсанд бараа нэмнэ | Хэрэглэгч төлбөр илгээнэ | Серверийн процесс гэнэт зогсоно | Хэрэглэгч тайлан нээнэ |
| Шаардлагатай хариу | JSON ба HTTP 200 хурдан ирнэ | Төлбөрийн дийлэнх хүсэлт HTTP 200 буцаана | Дахин асаасны дараа хүсэлтүүд амжилттай хариулна | Тайлангийн мөрийн тоо HTTP 200-тай ирнэ |
| Хэмжүүр | Сагсны p95 < 20 мс | Төлбөр алдах магадлал < 7.5% | Амжилтын магадлал ≥ 90%, сэргэлт ≤ 15 с | Тайлангийн p95 < 430 мс |

## SLO ба төсөв

| Сценарио | SLI | Босго | Цонх |
|---|---|---|---|
| Гүйцэтгэл | Сагсны хүсэлтийн хугацаа | p95 < 20 мс | 1 мин, 20 VU |
| Найдвартай байдал | Төлбөрийн алдааны хувь | < 7.5% | 1 мин, 20 VU |
| Бэлэн байдал | Бүх HTTP 200 шалгалтын хувь | ≥ 90% | 2 мин, 20 VU, 10 с зогсолт |
| Сэргэлт | Процесс зогссоноос эхний амжилттай probe хүртэлх хугацаа | ≤ 15 с | Chaos туршилт, тусдаа хэмжилт |
| Тайлан | Тайлангийн хүсэлтийн хугацаа | p95 < 430 мс | 1 мин, 20 VU |

Сагсанд зориудын хүлээлт байхгүй тул локал орчинд 20 мс-ийн хязгаар тавив. Төлбөрийн загварчилсан 5%-ийн алдаанд 2.5 нэгж хувийн зай үлдээв. Тайлангийн дээд хүлээлт 400 мс тул 430 мс нь нэмэлт боловсруулалтад 30 мс үлдээнэ. Бэлэн байдлын 90%-ийн зорилт нь 120 секундэд 12 секундын хугацааны төсөвтэй. Сэргэлтийн 15 секундийн хязгаар нь төлөвлөсөн зогсолт дээр дахин асахад 5 секунд нэмнэ.

## Ажиллуулах

```text
k6.exe v2.4.0 (commit/dd9395906d, go1.26.11, windows/amd64)
```

Эхний терминалд `node server.js` ажиллуулна. API зөвхөн локал 3203 порт дээр ажиллана. Хоёр дахь терминалд:

```powershell
New-Item -ItemType Directory -Force results | Out-Null
k6 run --no-color --quiet slo-test.js 2>&1 | Tee-Object results/pass.txt
k6 run --no-color --quiet -e MODE=chaos slo-test.js 2>&1 | Tee-Object results/chaos.txt
k6 run --no-color --quiet slo-test-fail.js 2>&1 | Tee-Object results/fail.txt
$LASTEXITCODE
```

Chaos гүйлт эхэлснээс ойролцоогоор 40 секундийн дараа серверийг зогсоож, 10 секунд хүлээгээд дахин асаана. Сагсны зам HTTP 200 буцаах хүртэлх хугацааг тусад нь хэмжинэ.
